The 3D mountain scene

On wider screens, a low-poly mountain turns beside my name. I wrote a brief with my palette colours and directed an AI assistant to build it in Three.js, one prompt at a time. The first snow cap was hidden inside the green peak, so I had it made slightly wider to sit over the surface, and I moved the camera low so it looks up at the summit like a hiker standing below it.

Next goals: JavaScript and open source

The mountain scene runs on JavaScript that I directed but did not write myself. My next goal is to go beyond HTML and CSS and learn to make pages that respond and do things. After that, I want to find a beginner-friendly project on GitHub and get my first pull request merged.
